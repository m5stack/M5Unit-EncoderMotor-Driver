# Changelog

All notable changes to this project are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-27

### Added

- Unified `M5UnitEncoderMotor` public API for U232 and U233.
- Separate single-channel and four-channel protocol drivers.
- PWM, encoder, speed, position, voltage, current, RGB, and device configuration APIs.
- Closed-loop speed examples for both products with RGB and telemetry output.
- Arduino and PlatformIO library metadata.
- Arduino Lint and clang-format CI checks.
